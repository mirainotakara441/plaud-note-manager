- [x] **3. 武器の保存が別の武器の記憶を消す** `app/api/weapons/route.ts:290`

  `weapon:<ID>:` 前方一致で別の武器の memory_chunks を巻き込んで purge する。
  → 2026-08-19: weaponIdOfをSHA-256ハッシュ（固定長64桁）に変更し衝突を構造的に解消。
  既存41件の旧形式weapon:データは孤児化（検索には影響なし）。一括削除の要否は要判断・未実施。

  連打で2回投稿される。投稿成功後の書き戻し失敗でも再投稿できてしまう。
  → 2026-08-19: ramen_logsにx_post_lock列を追加するマイグレーションを適用し、
  原子的UPDATEで排他制御。書き戻し失敗時はpost_failed_needs_reviewで自動再投稿を停止。

- [x] **5. 振り返りの編集で本文が消える** `app/api/retrospective/route.ts:316`

  → 2026-08-19: 共通関数replaceSectionsにDELETE前バックアップ＋INSERT失敗時の復元を追加し、
  POST/PATCH両方に効くよう統一。
