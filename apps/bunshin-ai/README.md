# 法人請求オンラインサービス相談AI（bunshin-ai）

画面上の名前は「法人請求オンラインサービス相談AI」。中身は吉井嗣和さんの分身AI。
これを、営業推進メンバー・支店営業・営業委託先に**URL1本で配る**ためのアプリ。
吉井さんに相談する前に、メンバーがここで一周考えを整理するための壁打ち相手。

## なぜ AIワークOS（aiworkos-dashboard）と別アプリなのか

AIワークOS本体は1人運用の前提で、**アプリ全体がひとつの合言葉で守られている**。
そこへ分身AIを足してメンバーに合言葉を配ると、日記・健康・家族・週報・人脈DBまで全部見える。
本体には `/qa-gate` のようにページ単位で別の合言葉をかける仕組みもあるが、
配る相手が増える前提のこのアプリは、**デプロイごと分けて事故の届く範囲を切る**方を選んだ。

- Vercelプロジェクト：本体とは別
- 合言葉：本体の `APP_PASSPHRASE` は一切使わない（`BUNSHIN_PASSPHRASE`）
- Supabase：本体と同じプロジェクトの `bunshin_logs` テーブルだけ使う

## 中身

| 場所 | 役割 |
|---|---|
| `content/instruction.md` | 分身AIの指示文（判断の芯＋語り口）。ワークショップで本人の面談から作ったもの |
| `content/voice.md` | 社内会議での本人の発言（**配布版**）。考え方の材料 |
| `content/decisions.md` | 判断実例集（**配布版**）。「〜のときは〜する」の型 |
| `lib/systemPrompt.ts` | 上の3つを連結してシステムプロンプトを組む |
| `app/page.tsx` | 会話画面 |
| `app/admin/page.tsx` | 相談ログ一覧（吉井さん専用） |
| `proxy.ts` | 全ページ・全APIの認証ゲート |

### ★ content/ に置くのは「配布版」だけ

全量は `~/Desktop/AI/分身AI/素材_*.md` にある。配布版は、そこから次を落としてある：

- 事業の継続可否（撤退するのかどうか）に関わる発言
- 特定メンバーの力量評価に関わる発言
- 社内の値付け・法務手続きの通し方

**メンバーが使うAIがこれを喋ると事故になる。** 素材を更新するときは、必ず配布版を作り直してから `content/` に入れること。

## 合言葉は2種類

| 環境変数 | 誰が使うか | 何ができるか |
|---|---|---|
| `BUNSHIN_PASSPHRASE` | メンバー | 分身AIと話せる |
| `BUNSHIN_ADMIN_PASSPHRASE` | 吉井さん | 上に加えて `/admin`（相談ログ）が開く |

管理用で入るとメンバー用のcookieも一緒に発行されるので、吉井さんが覚える合言葉は1つでよい。
全員を一斉に締め出したいときは Vercel の `BUNSHIN_PASSPHRASE` を変える。

## 相談ログ

ログイン時に入力した名前とセットで `bunshin_logs` に残り、`/admin` で新しい順に見られる。
「よく来る相談」の実測になり、指示文の改善に直結する。
ログイン画面に「記録され、吉井さんが見られる形で残る／評価や査定には使わない」と明記してある。

## 環境変数

`.env.local.example` を参照。Vercelにも同じものを設定する。

## 踏んだ罠

- **`proxy.ts` の `config.matcher` を書き忘れると、CSS/JS まで `/login` へリダイレクトされる。**
  画面がスタイルの当たっていない素のHTMLになって、原因が分かりにくい。
- 長い応答は**必ずストリーミング**で返す。非ストリーミングは60秒で切れる。
